inkast

A list anyone can add to and only you can read.

anyone ──URL──▶ ┃       ┃
anyone ──URL──▶ ┃  list ┃ ──key──▶ you
anyone ──URL──▶ ┃       ┃

Make one and you get a URL and a key. Anyone with the URL can add to the list. Anyone with the key can read it, or delete it. Nothing in between: no editing, no accounts.

curl -X POST https://inkast.0sk.ar
# gives you an id + a secret key for reading and deleting the list.
curl -d "the save button does nothing" https://inkast.0sk.ar/<id>
curl -H "Authorization: Bearer <key>" https://inkast.0sk.ar/<id>
