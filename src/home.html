inkast

A list anyone can add to and only you can read.

anyone ──URL──▶ ┃       ┃
anyone ──URL──▶ ┃  list ┃ ──key──▶ you
anyone ──URL──▶ ┃       ┃

Make a list and you get a URL and a key.

curl -X POST https://inkast.0sk.ar

Anyone with the URL can add to the list. Anyone with the key can read it, or delete it. Nothing in between: no editing, no accounts.

How it works. A side project, no guarantees. Don't send it anything you can't lose.
